# Shaktimaan

A personal Spec-Driven Development (SDD) toolkit — a CLI that scaffolds a
`specify → clarify → plan → tasks → analyze → checklist → implement →
converge` workflow into any project, plus a few extra commands
(`commit-push`, `prioritise-next`) and an opt-in requirements-tracking
bundle for PRD-style (FR-/NFR-/UAT-xxx) projects.

Inspired by [github/spec-kit](https://github.com/github/spec-kit) (MIT
licensed) — same workflow shape, own implementation, own commands.

Status: early scaffolding, not yet usable.
